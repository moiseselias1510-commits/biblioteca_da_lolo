# Nossa Biblioteca — fundos personalizados

Além da integração com Google Sheets, esta versão possui três fundos:

- `imagens/fundo-login.jpg` — tela de senha, o mesmo para os dois.
- `imagens/fundo-dela.jpg` — área dela.
- `imagens/fundo-meu.jpg` — sua área.

Coloque suas imagens nessa pasta. Se quiser PNG, altere os nomes no `config.js`.

Os fundos ocupam a tela inteira e recebem uma camada escura para o conteúdo continuar legível.

## Configuração
1. Cole a URL `/exec` do Google Apps Script em `config.js`.
2. Envie o projeto para o GitHub.
3. Ative GitHub Pages em `Settings > Pages > Deploy from a branch > main > /root`.

As funções de Google Sheets permanecem as da versão anterior.
